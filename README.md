## 💡 Problem Statement
### Problem Statement - 1: Best Use of the TinyFish Platform
*TinyFish is the execution layer for AI agents that need to interact with the real web. Build agents that can navigate websites, gather information, compare options, and complete complex browser-based workflows.*

*Instead of just generating answers, build AI agents that actually get things done on the web.*
